## Overview

AAS Strum is an acoustic guitar physical modeling instrument that captures the nuance of real strumming and picking through advanced string and body resonance simulation.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **AAS Strum** delivers the features you need in a clean, intuitive package.

</div>

## Key Features

| Feature | Description |
|---------|-------------|
| **Physical Modeling** | String stiffness, body resonance, and pick position fully simulated |
| **Strum Patterns** | Built-in rhythm patterns with adjustable tempo and swing |
| **Chord Library** | Hundreds of preloaded chord voicings across all major styles |
| **Expression Control** | Velocity and aftertouch map to pick dynamics and vibrato |
